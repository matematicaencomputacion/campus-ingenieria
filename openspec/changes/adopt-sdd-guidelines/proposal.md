# Adoptar lineamientos SDD

## Why
Los reportes de éxito pueden exceder lo que verifican los tests. Campus necesita
reglas compartidas entre copilotos que preserven el trabajo ya integrado.

## What Changes
Documentar stack real, límites de cobertura, protocolo de evidencia y flujo SDD;
conectar los copilotos a docs/base-standards.md e incorporar contexto OpenSpec.

## Capabilities
### New Capabilities
- `agent-guidelines`: fuente común de reglas verificables y específicas del proyecto.

## Impact
Solo documentación y configuración de agentes. Sin cambios de aplicación o CI.

## Fuera de alcance
Navegación masiva, CSS Fase 2, nuevos tests funcionales, activación del deploy,
instalación de skills de terceros o cambios de modelo.

## Rollback
Revertir el commit de adopción; no hay migraciones de datos.
