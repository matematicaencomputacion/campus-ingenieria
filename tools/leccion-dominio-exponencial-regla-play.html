Atajo · exponencial

  • Si ves e^{algo} o a^{algo} (a>0, a≠1) → el dominio es el del exponente.
  • Base inválida (a≤0 o a=1) → no usamos esa base aquí.

Regla · Dom(a^{f(x)}) = Dom(f)

Si a > 0 y a ≠ 1, entonces a^{f(x)} está definida en ℝ siempre que exista el exponente. Por lo tanto: Dom(a^{f}) = Dom(f). Caso e: Dom(e^{g}) = Dom(g).
