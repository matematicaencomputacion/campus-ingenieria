1 · Qué es esto

  • Una aplicación económica describe un mercado con funciones: si cambia la cantidad, cambia el precio, el costo o la ganancia.
  • No hace falta saber economía previa: cada palabra se define acá, con un dibujo.
Palabras (UDL)
  • precio p — cuánto se paga por una unidad (en $).
  • cantidad x — cuántas unidades se venden o se fabrican.
  • oferta — el vendedor ofrece más si el precio sube (recta que sube).
  • demanda — el comprador pide menos si el precio sube (recta que baja).
  • costo fijo — se paga aunque x = 0 (alquiler, máquina).
  • costo variable — crece cuando fabricás más.
  • costo total C — fijo + variable.
  • costo medio C̄ — C / x · cuánto sale cada unidad.
  • ingreso I — lo que entra: precio × cantidad.
  • beneficio B — I − C · si B>0, es rentable.
  • tramos — distinta fórmula según el intervalo de x.
